## 目标

把上轮中断的地方接上——`api.ts` 里补齐后端 21 个素材接口对应的客户端函数，解除 `AssetFolder` / `AssetScene` / `AssetTag` / `MediaAsset` 四个悬空 import。

这是图片工坊和草稿工坊选图两件界面工作的前置。

## 做了什么

在 `frontend/src/lib/api.ts` 末尾新增 22 个函数，覆盖全部 21 个端点：

- 文件夹：`fetchAssetFolders` / `createAssetFolder` / `updateAssetFolder` / `deleteAssetFolder`
- 产品：`fetchProducts` / `createProduct` / `updateProduct` / `deleteProduct`
- 场景：`fetchAssetScenes` / `createAssetScene` / `updateAssetScene` / `deleteAssetScene`
- 标签：`fetchAssetTags` / `createAssetTag` / `updateAssetTag` / `deleteAssetTag`
- 素材：`fetchMediaAssets`（含 `MediaAssetFilters` 类型）/ `createMediaAsset` / `batchUpdateMediaAssets` / `reorderMediaAssets` / `deleteMediaAsset`

请求与响应形状照 `backend/app/api/assets.py` 的 schema 和 `_serialize_*` 逐字段核对，前端既有类型定义（`types/index.ts:413-458`）与后端序列化完全一致，未作任何调整。

列表接口走 `Paginated<T>`，与 `fetchSavedNotes` 等既有函数同一模式。
