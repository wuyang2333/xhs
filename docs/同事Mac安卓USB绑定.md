# 安卓手机 USB 绑定（Windows / Mac）

全流程在网页里完成，**不需要命令行**。入口：账号矩阵 → 添加账号 → 安卓手机。

向导有 6 步，页面上每一步都直接带按钮。其中**只有第 2、3 步需要你在手机上手动操作**——那是安卓的安全设计，程序无法代替。

| 步骤 | 谁做 |
|---|---|
| 1. 安装 ADB 连接工具 | 点「一键安装 ADB」，系统自动从谷歌官网下载安装 |
| 2. 在手机上打开 USB 调试 | **你手动** |
| 3. 插线并在手机上点「允许」 | **你手动** |
| 4. 检测手机 | 点「检测已连接的手机」 |
| 5. 安装中文输入法 | 点「一键安装中文输入法」 |
| 6. 选择手机并绑定账号 | 你选择设备后点绑定 |

## 第 2 步：手机上打开 USB 调试

1. 设置 → 关于手机 → 连续点击「版本号」7 次，直到提示已进入开发者模式。
2. 返回设置 → 系统与更新（小米为「更多设置」）→ 开发者选项。
3. 打开「USB 调试」开关。
4. 小米 / 红米还需额外打开「USB 调试（安全设置）」，否则无法自动操作界面。

## 第 3 步：插线并授权

1. **保持手机解锁**。锁屏状态下不会弹出授权窗口。
2. USB 用途改为「文件传输 / MTP」。选「仅充电」时弹窗可能不出现。
3. 看到「允许 USB 调试吗？」时，**勾选「一直允许使用这台计算机进行调试」**再点「允许」。

## 第 4 步的两种状态

- `unauthorized`：手机看得到但还没授权。回到手机点「允许」，然后再点一次检测。没看到弹窗就把 USB 用途改成「文件传输」，或拔线重插。
- `device`：已就绪，可以继续。

## 第 5 步为什么必须做

adb 原生输入命令打不了中文。不装这个输入法，标题和正文就填不进去。装完不会改变你手机的默认输入法。

## 说明

- 安装 ADB 需要能访问 `dl.google.com`。国内网络通常要先开代理，失败时向导会显示具体原因。
- 重复点安装不会重复下载。
- 已经手动装过 adb（如 `brew install android-platform-tools`）会被自动识别，第 1 步直接显示已就绪。也可用 `XHS_ADB` 指定路径、`XHS_ADB_INSTALL_DIR` 改安装目录。
- 绑定信息按电脑保存在本机数据库。更换电脑后需在新电脑重新完成授权和账号映射；不会复制手机密码、Cookie 或 ADB 私钥。
